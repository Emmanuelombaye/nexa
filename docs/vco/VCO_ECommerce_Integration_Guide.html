VCO Telehealth Commerce Engine v1.0

Storefront Developer Integration Guide

Learn how to wire any custom brand storefront (such as PeakCare, or any future white-label brand tenant) to the VirtualClinicOS (VCO) Headless E-Commerce & Telehealth Backend.

How VirtualClinicOS Connects to Your Brand

VirtualClinicOS functions as a Headless Telehealth & Fulfillment Engine. Your brand website (built with Next.js, React, or any framework) handles the marketing design, product displays, and customer UX, while delegating catalog syncing, medical questionnaires, clinical chart routing, Stripe payouts, and pharmacy fulfillment to VCO.

1

Brand Storefront

Next.js frontend fetches active products and displays treatment protocols.

2

Medical Intake

Collects patient symptoms, DOB, health history, and shipping state.

3

VCO Checkout API

Creates patient record, encrypts PHI (AES-256), and generates Stripe session.

4

Doctor & Pharmacy

Licensed clinician reviews order in Doctor Portal and pushes Rx to pharmacy.

Multi-Tenant Isolation: Each brand is a dedicated tenant in VCO. Every API request identifies your tenant using your brandId (e.g. peakcare) or your hashed API Key (phk_live_...). VCO automatically isolates products, orders, doctors, and payouts per brand.

Authentication & Environment Variables

Add the following variables to your brand storefront's .env.local file:

.env.local 
# VirtualClinicOS API Base URL
NEXT_PUBLIC_VCO_API_URL=https://portal.virtualclinicos.com
# For local sandbox development, you can use:
# NEXT_PUBLIC_VCO_API_URL=http://localhost:3000

# Your Brand Tenant Identifier (e.g. peakcare, trimrx, etc.)
NEXT_PUBLIC_VCO_BRAND_ID=peakcare

# Your Private API Key (Used in server-side API routes & Next.js Server Components)
VCO_API_KEY=phk_live_your_brand_api_key_here
Header / Parameter Type Required Description
Authorization string Required for Server APIs Bearer vco_live_.... Your brand tenant's private API key.
x-brand-id string Optional Your brand slug or tenant UUID (e.g. vitalwellrx). Can also be passed as query parameter ?brandId=vitalwellrx.
Content-Type string Required application/json

POST /api/commerce/v1/checkout/session Create Stripe Checkout Session + Patient Order

The central checkout endpoint. It creates or matches the patient profile in VCO, stores encrypted medical intake questionnaire answers, calculates doctor & platform fees, and returns a Stripe Checkout URL.

Field Type Required Description
brandId string Required Brand slug (e.g. peakcare) or tenant UUID.
productId string Required Product UUID, SKU, or slug.
patientInfo object Required Contains firstName, lastName, email, state (2-letter US code e.g. TX), optional phone and dob (YYYY-MM-DD).
intakeAnswers object Required Key-value map of patient answers from your medical intake questionnaire. Encrypted at rest via AES-256-GCM.
couponCode string Optional Discount code string if applied.
successUrl string Required Where to redirect patient after successful payment (e.g. https://peakcare.com/checkout/success?session_id={CHECKOUT_SESSION_ID}).
cancelUrl string Required Where to redirect patient if they cancel checkout.

Step-by-Step Storefront Wire-up Guide

Step 1: Create the Reusable Commerce Client (src/lib/commerce.ts)

In your Next.js project, create a single client module to communicate with VCO:

src/lib/commerce.ts 
// VCO Commerce Client for Storefront
export interface VCOProduct {
  id: string;
  name: string;
  slug: string;
  description: string;
  price: string;
  treatment_protocol?: string;
  images: string[];
  contraindications?: string;
  screening_questions?: string[];
  requires_intake: boolean;
}

const vcoBaseUrl = (process.env.NEXT_PUBLIC_VCO_API_URL || 'https://portal.virtualclinicos.com').replace(/\/$/, '');
const brandId = process.env.NEXT_PUBLIC_VCO_BRAND_ID || 'peakcare';
const apiKey = process.env.VCO_API_KEY || '';

// Fetch all active products
export async function fetchProducts(): Promise {
  try {
    const res = await fetch(`${vcoBaseUrl}/api/commerce/v1/products?brandId=${brandId}`, {
      headers: {
        'Authorization': `Bearer ${apiKey}`,
        'Content-Type': 'application/json',
      },
      next: { revalidate: 60 }, // Cache on Edge for 60 seconds
    });

    if (!res.ok) throw new Error(`Failed to fetch catalog: ${res.status}`);
    const data = await res.json();
    return data.products || [];
  } catch (err) {
    console.error('[VCO Commerce] fetchProducts error:', err);
    return [];
  }
}

// Fetch single product by slug
export async function fetchProductBySlug(slug: string): Promise {
  try {
    const res = await fetch(`${vcoBaseUrl}/api/commerce/v1/products/${slug}?brandId=${brandId}`, {
      headers: {
        'Authorization': `Bearer ${apiKey}`,
        'Content-Type': 'application/json',
      },
      next: { revalidate: 60 },
    });
    if (!res.ok) return null;
    const data = await res.json();
    return data.product || null;
  } catch (err) {
    console.error('[VCO Commerce] fetchProductBySlug error:', err);
    return null;
  }
}

Step 3: Wire Checkout Execution (src/app/api/checkout/session/route.ts)

Proxy the checkout request securely through your Next.js route handler to protect your VCO_API_KEY:

src/app/api/checkout/session/route.ts 
import { NextRequest, NextResponse } from 'next/server';

const vcoBaseUrl = (process.env.NEXT_PUBLIC_VCO_API_URL || 'https://portal.virtualclinicos.com').replace(/\/$/, '');
const brandId = process.env.NEXT_PUBLIC_VCO_BRAND_ID || 'peakcare';
const vcoApiKey = process.env.VCO_API_KEY || '';

export async function POST(req: NextRequest) {
  try {
    const body = await req.json();

    // Call VCO Commerce Engine
    const res = await fetch(`${vcoBaseUrl}/api/commerce/v1/checkout/session`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${vcoApiKey}`,
      },
      body: JSON.stringify({
        brandId,
        productId: body.productId,
        patientInfo: body.patientInfo,
        intakeAnswers: body.intakeAnswers,
        couponCode: body.couponCode,
        successUrl: `${req.nextUrl.origin}/checkout/success?session_id={CHECKOUT_SESSION_ID}`,
        cancelUrl: `${req.nextUrl.origin}/shop`,
      }),
    });

    const data = await res.json();
    if (!res.ok) {
      return NextResponse.json({ error: data.error || 'Checkout failed' }, { status: res.status });
    }

    return NextResponse.json(data);
  } catch (err: any) {
    console.error('[Checkout Error]:', err);
    return NextResponse.json({ error: err.message || 'Internal Server Error' }, { status: 500 });
  }
}

Errors & Troubleshooting Checklist

Status Code Error Message Root Cause & Solution
401 Unauthorized "brandId query param or valid Authorization Bearer API key required" Ensure you are sending Authorization: Bearer phk_live_... or passing ?brandId=your_brand in the URL.
400 Bad Request "Invalid checkout request format" Check your patientInfo payload. state must be a 2-letter uppercase US state code (e.g. CA, TX, FL), and email must be valid.
404 Not Found "Product not found for this brand" The productId or slug belongs to another tenant or is marked as draft / portal_only in VCO. Check the product's visibility in Admin Portal.
500 Server Error "Stripe Connect account not configured" The brand tenant has not connected their Stripe account yet. Navigate to /admin/{brandId}/commerce in VCO and complete Stripe Connect onboarding.
